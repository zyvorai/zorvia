Feature Overview

Complete KubeVirt VM management from the command line.

VM Lifecycle

CommandDescription
zorvia createCreate a VM from template, profile, or YAML config
zorvia listList all VMs with status, CPU, memory, IP, node, age
zorvia start / stop / restartControl VM power state via KubeVirt RunStrategy
zorvia statusDetailed VM status with resources, volumes, conditions
zorvia cloneClone an existing VM with new name
zorvia exportExport VM configuration to YAML/JSON
zorvia deleteDelete a VM with confirmation
zorvia generateGenerate VM manifest without creating it
zorvia validateValidate a VM configuration file before deployment
zorvia diffCompare two VM configurations side by side

Quick Start

# Create an Ubuntu 24.04 VM with 4 CPUs and 8GB RAM
$ zorvia create --name web-01 --template ubuntu-24.04 \
    --cpus 4 --memory 8Gi --disk 50Gi

# List all VMs
$ zorvia list
NAME          NAMESPACE   STATUS    RUNNING   CPU       MEMORY
web-01        default     Running   Yes       4 cores   8Gi

# Take a snapshot
$ zorvia snapshot create web-01 --name before-upgrade

# Use the interactive TUI
$ zorvia tui
